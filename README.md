# Oracle Developer Toolkit

Reusable Oracle SQL, PL/SQL, and Oracle APEX utilities for initialization, diagnostics, monitoring, testing, and maintenance.

## Structure

```text
oracle-dev-toolkit/
├── initialization/
│   ├── sequence-generators/
│   ├── logging/
│   ├── audit-columns/
│   ├── constraints/
│   └── indexes/
├── diagnostics/
├── monitoring/
├── testing/
├── maintenance/
├── apex/
└── examples/
    └── rms/
```

## Planned Utilities

- Sequence generators using triggers
- Identity-based alternatives
- Row-history/logging generators
- Audit-column helpers
- Constraint and index helpers
- Schema diagnostics
- Monitoring scripts
- Testing helpers
- Maintenance scripts
- Oracle APEX utilities

## Compatibility

The toolkit is intended to cover both legacy and modern Oracle techniques where practical.
